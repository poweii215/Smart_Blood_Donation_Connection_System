SBDCs - Run Guide

1) Open Docker Desktop and wait until Engine is running.
2) Open terminal in this folder.
3) First run:
   docker compose up --build

4) Open web:
   http://localhost:3000

5) API docs:
   http://localhost:8000/docs

For later runs:
   docker compose up

Stop:
   docker compose down
